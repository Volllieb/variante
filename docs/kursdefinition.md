# kursdefinition.md — variante

> **Stand: 20.08.2026** — nach Urlaubs-Neubewertung festgelegt. Verbindlich bis zum ersten zahlenden Pro-Kunden. Wo `gotomarket.md` oder `PROJEKT.md` abweichen, gilt dieses Dokument.

## Erfolgskriterium (nächste 90 Tage)

**Erster zahlender Pro-Kunde (35 €/Mo) bis ~18.11.2026.**

Alles andere — Case-Studies, Product Hunt, Badge-Reichweite, Features — ist Mittel dazu, nicht Ziel. Nach dem ersten Kunden: 10 zahlende (Pro) in 60–90 Tagen, danach 500–1.000 €/Mo passives Asset.

## Metriken: Sales-Pipeline (pro Kanal getrennt)

| # | Stufe | Metrik | Ziel |
|---|---|---|---|
| 1 | Leads | Kontakte identifiziert (Kanal A / Kanal B) | wöchentlich wachsend |
| 2 | Outreach | Gespräche geführt · Antwortrate | dokumentiert pro Kanal |
| 3 | Concierge-Setup | Erste Tests FÜR Partner aufgesetzt | 3–5 |
| 4 | Aktivierung | Live-Tests auf fremden Sites | ≥3 parallel |
| 5 | Conversion | Trial → Pro (Checkout abgeschlossen) | **1** ← der Punkt |

> Die alte North-Star-Metrik (% Installs → Live-Test) wird reaktiviert, sobald die Pipeline Volumen hat (>100 Installs/Traffic). Vorher misst sie nichts — bei 1 Signup in 6 Wochen ist sie Leerlauf.

## Die zwei Lead-Kanäle

| | **Kanal A — Figma** | **Kanal B — Landingpage** |
|---|---|---|
| **Segment** | Designer, Design-Partner, Design-Agencies, Figma Developers | Indie Hacker, AI-Builder (v0/Bolt/Lovable), Gründer |
| **Vehikel** | Plugin (Community Store), Figma-Foren, Reviews | www.getvariante.com, SEO, Product Hunt |
| **Methode** | Design-Partner-Outreach (Loom-DMs), Concierge-Onboarding | Self-Serve (ab.js + Auto-Optimize-Pfad), PH-Launch |
| **Value-Prop** | „A/B-Test direkt aus Figma" | „Kein Dev nötig — KI macht den Test" |
| **Aha-Moment** | Live-Stats im Editor | Test in ~30s ohne Code |

**Trennung ist Absicht:** Designer-Segment und Indie-Hacker-Segment kaufen unterschiedlich. Kanal A spricht Designer über den Plugin-Store an, Kanal B Gründer über die Landingpage. Kein Misch-Messaging.

## Entscheidungsregeln

Jede Arbeit (Feature, Post, Outreach, Refactor) muss **eine** dieser Fragen mit Ja beantworten:

1. Trägt sie zu Kanal A (Figma) oder Kanal B (Landingpage) bei?
2. Bewegt sie die Sales-Pipeline eine Stufe vorwärts (Lead → Gespräch → Test → Pro)?

Sonst: **nicht machen.** Auch wenn's Spaß macht oder technisch elegant ist.

## 90-Tage-Plan (20.08. → 18.11.2026)

- **Woche 1–2: Bestandsaufnahme.** Plugin-Stats, Signups, Outreach-Antworten der letzten 4 Wochen. Uncommitted Stand (77 Files vom Re-Audit) committen. Pipeline-Baseline pro Kanal.
- **Woche 1–6: Kanal A anlaufen.** Design-Partner-Outreach (Loom-DMs), Concierge-Onboarding, erste Live-Tests auf Partnersites.
- **Woche 4–8: Kanal B vorbereiten.** Landingpage für Indie-Hacker schärfen, PH-Material (Demo-GIF, Case-Study-Ansätze).
- **Woche 8–10: Product Hunt Launch** (Kanal B), parallel Concierge (Kanal A).
- **Woche 10–13: Conversion-Fokus.** Erste Partner auf Pro bringen.
